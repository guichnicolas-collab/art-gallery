# Art Gallery

Browse art from the Met Museum API

## Features

- Search art by name, author, or keyword
- View details of the artwork (name, author, date etc.) along with an image
- Browse through more images

### Tech Stack

- **Vanilla JavaScript**
- **[MetMuseum API](https://metmuseum.github.io/)**
